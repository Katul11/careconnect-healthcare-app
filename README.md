# CareConnect — Healthcare Appointment Booking App

## About the Project
CareConnect is a mobile UI/UX design project that helps patients find doctors and book healthcare appointments easily.

## Tools Used
- Figma
- GitHub

## Key Features
- Doctor search and specialty filters
- Doctor profiles and consultation fees
- Appointment date and time selection
- Booking confirmation
- Appointment management
